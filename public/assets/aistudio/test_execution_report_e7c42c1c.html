9. Test Execution Evaluation

The test execution covers the seven major modules of the PLATEA campus food-ordering kiosk prototype. A total of 27 test cases are prepared to evaluate the interface navigation, menu category filtering, Add to Cart confirmation, cart review, payment selection, and order confirmation.

Both positive and negative test scenarios are included to assess whether the prototype behaves according to its expected functions. The results of each test case will help identify possible interaction issues and areas that require improvement.

Any failed test cases should be reviewed by the project team. Necessary corrections should be applied, followed by retesting to verify whether the identified issues have been resolved.

10. Conclusion

The Test Execution Report provides a structured assessment of the PLATEA prototype based on its designed interface and intended user interactions. The testing activities focus on verifying the major functions involved in the campus food-ordering process, from accessing the Welcome Page to viewing the final order confirmation.

The test results will serve as a reference for evaluating the functionality, navigation, and consistency of the prototype. Identified issues will be used as a basis for improving the design and ensuring a smooth and understandable ordering experience for students.
